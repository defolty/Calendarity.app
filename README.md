# Calendarity - Сайт мобильного приложения

Официальный сайт мобильного приложения Calendarity для управления временем и планирования задач.

## 📱 О приложении

Calendarity - это современное мобильное приложение для эффективного управления временем, календарем и задачами. Приложение предоставляет интуитивный интерфейс для планирования событий, создания напоминаний и отслеживания продуктивности.

## 🌐 Структура сайта

Сайт содержит следующие страницы:

- **index.html** - Главная страница с описанием приложения и его возможностей
- **privacy.html** - Политика конфиденциальности
- **terms.html** - Пользовательское соглашение

## 🎨 Технологии

- HTML5
- Tailwind CSS (через CDN)
- Адаптивный дизайн (mobile-first)
- Modern JavaScript (при необходимости)

## 🚀 Запуск локально

Для локального просмотра сайта:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/defolty/Calendarity.app.git
```

2. Откройте `index.html` в браузере или используйте локальный сервер:
```bash
# С помощью Python
python -m http.server 8000

# С помощью Node.js
npx serve
```

3. Откройте браузер и перейдите по адресу `http://localhost:8000`

## 📦 Развертывание

Сайт автоматически публикуется через GitHub Pages на кастомный домен:
[https://calendarity.app](https://calendarity.app)

## 🔧 Настройка GitHub Pages с кастомным доменом

### 1. Настройка GitHub Pages

1. Перейдите в **Settings** → **Pages** вашего репозитория
2. В разделе **Source** выберите ветку `main` (или другую основную ветку)
3. В разделе **Custom domain** введите: `calendarity.app`
4. Включите опцию **Enforce HTTPS** (после настройки DNS)

### 2. Настройка DNS у регистратора домена

У вашего регистратора домена (где вы купили calendarity.app) добавьте следующие DNS записи:

#### Для корневого домена (calendarity.app):

Добавьте **A записи** для GitHub Pages:
```
Type: A
Name: @
Value: 185.199.108.153

Type: A
Name: @
Value: 185.199.109.153

Type: A
Name: @
Value: 185.199.110.153

Type: A
Name: @
Value: 185.199.111.153
```

#### Для поддомена www (опционально):

```
Type: CNAME
Name: www
Value: defolty.github.io
```

### 3. Проверка настройки

После настройки DNS (может занять до 24 часов):
- Проверьте доступность сайта по адресу https://calendarity.app
- Убедитесь, что SSL сертификат активирован в настройках GitHub Pages

### 4. Файл CNAME

В репозитории уже создан файл `CNAME` с доменом `calendarity.app`. Этот файл сообщает GitHub Pages, какой кастомный домен использовать.
