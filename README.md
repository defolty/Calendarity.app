# Calendarity - Сайт мобильного приложения

Официальный сайт мобильного приложения Calendarity для управления временем и планирования задач.

## 📱 О приложении

Calendarity - это современное мобильное приложение для эффективного управления временем, календарем и задачами. Приложение предоставляет интуитивный интерфейс для планирования событий, создания напоминаний и отслеживания продуктивности.

## 🌐 Структура сайта

Сайт содержит следующие страницы:

- **index.html** - Главная страница с описанием приложения и его возможностей
- **privacy.html** - Политика конфиденциальности
- **terms.html** - Пользовательское соглашение

## 🎨 Технологии

- HTML5
- Tailwind CSS (через CDN)
- Адаптивный дизайн (mobile-first)
- Modern JavaScript (при необходимости)

## 🚀 Запуск локально

Для локального просмотра сайта:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/defolty/Calendarity.app.git
```

2. Откройте `index.html` в браузере или используйте локальный сервер:
```bash
# С помощью Python
python -m http.server 8000

# С помощью Node.js
npx serve
```

3. Откройте браузер и перейдите по адресу `http://localhost:8000`
